## 📖 Part 1: 理论学习 (30分钟)

### 1.1 什么是"AI原生"？

**🧒 小学生版解释**:

想象你开了一家餐厅，需要一个服务员：

| 传统程序 (背台词) | AI Agent (即兴表演) |
|---|---|
| "如果客人要水，请倒水" | "客人看起来咳嗽，我主动问要不要热水" |
| "如果客人投诉，请道歉" | "我观察到客人皱眉，主动询问是否满意" |
| 必须预设所有情况 | 能处理从没见过的情况 |

**🎓 面试话术**:
> "传统程序依赖开发者穷举所有分支逻辑，维护成本高。AI-Native 利用 LLM 的泛化推理能力，能处理 long-tail 场景，在不确定性环境下更具优势。"

### 1.2 Orchestrator-Workers 模式

**🧒 小学生版解释**:

这就像一个"老板+员工"的分工：
- **Orchestrator (大脑/老板)**: 听客人说"我想去北京玩3天"，然后分解任务：
  - "小张，你去查景点"
  - "小李，你去查天气"
  - "小王，你去订酒店"
- **Workers (手脚/员工)**: 各自执行专业任务，汇报结果给老板

```
              用户: "去北京玩3天"
                      │
                      ▼
            ┌─────────────────────┐
            │    Orchestrator     │
            │   (理解+分解+汇总)   │
            └──────────┬──────────┘
                       │
         ┌─────────────┼─────────────┐
         ▼             ▼             ▼
   ┌──────────┐  ┌──────────┐  ┌──────────┐
   │  Scout   │  │  Meteo   │  │Concierge │
   │ 查景点   │  │ 查天气   │  │ 订酒店   │
   └──────────┘  └──────────┘  └──────────┘
```

**🎓 面试话术**:
> "我采用 Orchestrator-Workers 模式实现关注点分离。Orchestrator 负责意图理解和任务编排，Workers 专注单一职责。这种设计提高了可维护性和可扩展性，类似微服务架构思想。"
