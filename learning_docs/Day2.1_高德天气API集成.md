## 📖 Part 1: 概念理解

### 🎭 比喻：从"塑料假手"到"机械臂"

| Phase 1 | Phase 2 |
|---------|---------|
| 假数据 `{"北京": "晴天"}` | **真实 API 调用** |
| 数据永远不变 | **实时更新** |
| 像给机器人装了塑料假手 | 像给机器人装了**真正的机械臂** |

### 🔑 高德 API 能力一览

| 功能 | 用途 | 我们用到 |
|------|------|----------|
| 天气查询 | 实时天气、预报 | ✅ Day 2.1 |
| POI搜索 | 景点、餐厅、酒店 | ⏳ Day 2.2 |
| 地理编码 | 地址→经纬度 | 可选 |
| 路线规划 | 驾车、步行路线 | 可选 |

### ⚠️ 注意事项

**Key 类型必须匹配**：
| Key 类型 | 用途 | 我们需要 |
|----------|------|----------|
| Web端(JS API) | 网页显示地图 | ❌ |
| **Web服务** | 后端调用查数据 | ✅ |

## 🔧 Part 2: 实战代码

### 核心代码结构

```python
# 1. 城市编码（高德需要 adcode，不是城市名）
CITY_CODES = {
    "北京": "110000",
    "上海": "310000",
    ...
}

# 2. 请求参数
params = {
    "key": AMAP_API_KEY,
    "city": city_code,
    "extensions": "base",  # base=实况, all=预报
    "output": "JSON"
}

# 3. 发送请求（注意：国内API需要禁用代理）
response = requests.get(
    url,
    params=params,
    proxies={"http": None, "https": None}
)
```

### 关键知识点

| 知识点 | 说明 |
|--------|------|
| `extensions=base` | 返回当前实况 |
| `extensions=all` | 返回实况 + 未来4天预报 |
| 禁用代理 | 国内 API 不需要走代理 |
| 城市编码 | 高德用 adcode，不是城市名 |

## 🎓 面试话术

### Q: 你是如何集成第三方 API 的？

> "我集成了高德地图 Web API，使用 requests 库进行 HTTP 调用。
> 需要注意的是：
> 1. API Key 类型要匹配（Web服务 vs JS API）
> 2. 国内 API 需要禁用代理
> 3. 用 Pydantic 验证返回数据格式"

### Q: 遇到过什么问题？

> "遇到过 `USERKEY_PLAT_NOMATCH` 错误，是因为 Key 类型不对。
> 高德的 JS API Key 和 Web服务 Key 是不同的，
> 后端调用必须用 Web服务 类型的 Key。"
