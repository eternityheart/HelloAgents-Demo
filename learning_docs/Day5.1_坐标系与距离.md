## 📖 Part 1: 火星坐标系 (GCJ-02)

### 🧐 什么是 GCJ-02？
你刚刚的回答选了 A (为了精确)，其实标准答案是 **B (国家安全)**。
- **WGS-84**: 国际通用的 GPS 坐标系 (Google Earth 用这个)。
- **GCJ-02**: 中国国家测绘局制定的加密坐标系，俗称"火星坐标系"。它在 WGS-84 的基础上进行了一种非线性的偏移。

### 🚨 为什么要懂这个？
如果你直接把 GPS 采集的 WGS-84 坐标画在高德地图上，会发现**偏移了 300-500 米**！
- 比如你站在路东，地图上显示你在路西。
- **高德/腾讯** 使用 GCJ-02。
- **百度** 更狠，它在 GCJ-02 基础上又加密了一次，叫 **BD-09**。

虽然我们的 Demo 只是简单的距离排序，但作为专业工程师，必须知道：**不同坐标系的数据不能直接计算距离**。

## 🎓 面试话术

### Q: 为什么计算距离不用简单的欧氏距离？
> "因为经纬度是在球面上。同样的经度差，在赤道和在北极代表的实际距离是完全不一样的。
> 所以必须使用 Haversine 公式来计算球面大圆距离。"

### Q: 怎么处理国内地图的坐标偏移？
> "我在项目中统一使用 GCJ-02 坐标系。
> 高德 API 返回的就是 GCJ-02。如果我有用户的真实 GPS 坐标 (WGS-84)，在调用 API 或计算距离前，我会先使用 `coord-transform` 库将其纠偏转换为 GCJ-02，确保在同一个坐标系下进行计算。"
