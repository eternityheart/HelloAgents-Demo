# Git 分支工作流演示

> 这个文件是用来演示正确的 Git 分支工作流程的

## 演示目的
展示从 feature 分支到 PR 合并的完整流程

## 步骤回顾
1. ✅ `git checkout -b feature/git-workflow-demo` - 创建并切换到功能分支
2. ✅ 添加新文件/修改代码
3. ⏳ `git add .` + `git commit` - 提交到本地
4. ⏳ `git push origin feature/git-workflow-demo` - 推送到远程分支
5. ⏳ 去 GitHub 创建 Pull Request
6. ⏳ 审核确认后合并到 main
