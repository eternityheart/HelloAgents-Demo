# Phase 7: 时空指挥中心 (Time-Space Command Center) 🚀

> **设计理念**: 融合哆啦A梦的未来科技感与 Agentic Workflow 的工程叙事
> **核心体验**: 用户像坐在时空穿梭机的驾驶舱，调度多个 AI Agent 执行任务

---

## 🎨 设计规范 (Design Spec)

### 1. 色彩系统 (Color Palette)

| 用途 | 颜色 | Hex |
|------|------|-----|
| **主背景** | 深空蓝 | `#0a0e27` |
| **次背景** | 星云紫 | `#1a1f4e` |
| **玻璃面板** | 半透明白 | `rgba(255,255,255,0.08)` |
| **主强调色** | 哆啦A梦蓝 | `#00d4ff` |
| **次强调色** | 任意门粉 | `#ff6b9d` |
| **成功色** | 时光机绿 | `#00ff88` |
| **警告色** | 记忆面包黄 | `#ffd93d` |

### 2. 视觉元素 (Visual Elements)

#### 🌀 时空门 (Portal)
- **用途**: Agent 启动/加载动画
- **效果**: 同心圆旋转 + 粒子发射
- **触发**: 当 Agent 被调用时

#### 📡 HUD 面板 (Heads-Up Display)
- **效果**: 玻璃拟态 (Glassmorphism) + 边框呼吸灯
- **元素**: 扫描线动画、数据闪烁
- **用途**: 显示 Agent 状态、工具调用日志

#### 🗺️ 星图背景 (Star Map)
- **效果**: 缓慢移动的星点 + 网格线
- **意义**: 象征"探索未知"的 AI 旅程

#### 💬 对话气泡 (Chat Bubbles)
- **用户消息**: 右侧，任意门粉边框
- **Agent 消息**: 左侧，时光机绿边框，打字机效果

## ⚡ 动效设计 (Animations)

### 1. Portal 加载动效
```css
@keyframes portal-spin {
  0% { transform: rotate(0deg); }
  100% { transform: rotate(360deg); }
}
```
- 当 Agent 被激活时，对应卡片显示旋转的时空门

### 2. 扫描线效果
```css
@keyframes scan-line {
  0% { top: 0%; }
  100% { top: 100%; }
}
```
- HUD 面板上持续移动的水平线

### 3. 呼吸灯边框
```css
@keyframes breathing {
  0%, 100% { box-shadow: 0 0 5px #00d4ff; }
  50% { box-shadow: 0 0 20px #00d4ff; }
}
```
- Agent 卡片边框的脉冲效果

### 4. 打字机效果
- SSE 数据逐字显示，模拟 AI 思考过程

## 🔌 后端适配 (Backend Adaptations)

为了支持前端的炫酷展示，我们需要调整 SSE 输出格式：

```json
// 旧格式
{ "data": "🧠 思考中..." }

// 新格式 (增加 agent_id 和 event_type)
{
  "event": "thinking",
  "agent": "concierge",
  "content": "正在分析您的需求..."
}
{
  "event": "tool_call",
  "agent": "scout",
  "tool": "search_poi",
  "args": {"city": "北京", "keyword": "烤鸭"}
}
{
  "event": "tool_result",
  "agent": "scout",
  "status": "success",
  "content": "找到了 5 个烤鸭店..."
}
{
  "event": "response",
  "agent": "concierge",
  "content": "为您推荐以下烤鸭店：..."
}
```
