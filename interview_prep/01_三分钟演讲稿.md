# 🎤 3分钟项目介绍演讲稿

## 【开场白】(15秒)
> "大家好，我今天要介绍的是一个基于 **HelloAgents 框架** 的多智能体旅行规划系统。它能让用户用自然语言描述旅行需求，系统自动调度多个 AI Agent 协作完成复杂的行程规划。"

---

## 【项目背景】(30秒)
> "传统旅行规划工具依赖固定的流程和表单，无法灵活应对用户的多样化需求。
> 
> 我的解决方案采用 **AI-Native** 思想：
> - 用户说 '北京3日游，想看历史古迹'
> - 系统自动分解为：查天气 → 搜景点 → 找餐厅 → 订酒店
> - 最终生成一份可执行的多日行程方案"

---

## 【技术架构】(60秒)
> "系统采用 **Orchestrator-Workers** 模式，分为四层："

### 1️⃣ 编排层 (Orchestrator)
> "Orchestrator 是系统的大脑，负责意图理解和任务分解。它使用 DeepSeek LLM 配合 Pydantic 强类型校验，将用户的自然语言转化为结构化的行动计划。"

### 2️⃣ 能力层 (Workers)
> "我设计了三个专家 Agent：
> - **Scout** 负责景点和餐厅搜索
> - **Meteorologist** 负责天气查询
> - **Hotel** 负责酒店推荐
> 
> 每个 Agent 使用 **MCP 协议** 封装外部 API，实现工具标准化和复用。"

### 3️⃣ 服务层 (Backend)
> "后端基于 **FastAPI**，通过 **SSE** 实现流式输出，让用户能实时看到 Agent 的思考过程，类似 ChatGPT 的打字机效果。"

### 4️⃣ 展示层 (Frontend)
> "前端使用原生 JavaScript + 高德地图 API，实现了对话界面和地图可视化的双模式交互。用户可以切换'对话模式'和'规划模式'。"

---

## 【技术亮点】(45秒)
> "这个项目有三个核心技术亮点："

### 亮点1: MCP 工具标准化
> "通过 Model Context Protocol 思想，将高德 API 封装为标准工具，Agent 可以根据上下文自主选择调用，降低了集成成本。"

### 亮点2: 多源数据语义整合
> "Orchestrator 不只是简单拼接 Agent 返回的数据，而是让 LLM 进行语义融合，生成更自然、更有逻辑的旅行建议。"

### 亮点3: 结构化行程生成
> "系统能输出 Pydantic 校验的 JSON 格式多日行程，包含每天的景点、餐厅、酒店安排，并支持天气适配。"

---

## 【结语】(30秒)
> "这个项目完整落地了 **Agentic Workflow** 的工程实践：
> - 从自然语言输入到结构化输出
> - 从单一 LLM 调用到多 Agent 协同
> - 从后端推理到前端可视化
> 
> 通过这个项目，我深入理解了 AI Agent 系统的架构设计和工程化挑战。
> 
> 谢谢大家，我的介绍完毕。"

---

## 📝 备用问答准备

### Q1: 为什么选择 HelloAgents 而不是 LangChain？
> "HelloAgents 更透明、代码更简洁，适合学习和理解 Agent 原理。生产环境我会考虑 LangGraph 的 checkpointing 机制。"

### Q2: 如何处理 LLM 幻觉问题？
> "三层防御：
> 1. Prompt 层：明确指示只使用工具返回的真实数据
> 2. 数据层：Pydantic 强类型校验
> 3. 业务层：对关键坐标字段进行范围检查"

### Q3: 系统如何扩展新的 Agent？
> "只需要创建新的 Python 文件，用 @mcp.tool 装饰器注册工具，然后在 Orchestrator 的 Prompt 中添加工具说明即可。"
