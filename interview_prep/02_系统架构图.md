## 2. 数据流时序图

```mermaid
sequenceDiagram
    participant U as 用户
    participant F as 前端 (app.js)
    participant B as 后端 (FastAPI)
    participant O as Orchestrator
    participant S as Scout Agent
    participant W as Weather Agent
    participant H as Hotel Agent
    participant L as LLM (DeepSeek)

    U->>F: "北京3日游，喜欢历史"
    F->>B: POST /api/itinerary
    B->>O: generate(北京, 3, [历史])
    
    par 并行调用
        O->>W: get_weather(北京)
        W-->>O: 晴, 5℃
    and
        O->>S: search_poi(北京, 历史, 景点)
        S-->>O: 故宫, 天坛, 颐和园...
    and
        O->>S: search_poi(北京, 美食, 餐厅)
        S-->>O: 全聚德, 便宜坊...
    and
        O->>H: search_hotel(北京, min_rating=4.0)
        H-->>O: 北京饭店, 国贸大酒店...
    end

    O->>L: 整合结果，生成行程 JSON
    L-->>O: 结构化 Itinerary

    O-->>B: Itinerary 对象
    B-->>F: JSON Response
    F->>U: 展示多日行程卡片
```

## 5. 技术栈总览

| 层级 | 技术选型 | 说明 |
|-----|---------|-----|
| LLM | DeepSeek Chat | 中文优化，性价比高 |
| Agent 框架 | HelloAgents + FastMCP | 轻量、透明、教学友好 |
| 后端 | FastAPI + Uvicorn | 异步高性能，SSE 支持 |
| 数据校验 | Pydantic V2 | 强类型，自动序列化 |
| 前端 | Vanilla JS + 高德 JS API | 无框架依赖，原生实现 |
| 地图服务 | 高德 Web Service API | POI/天气/路线 |
